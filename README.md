# 🐱 Gatices - Blog sobre Gatos

Bem-vindo ao **Gatices**, um blog dedicado a compartilhar dicas, curiosidades e cuidados sobre nossos amigos felinos! 😻

Este projeto foi desenvolvido com HTML, CSS e JavaScript puros, com foco em um layout limpo e otimizado para monetização via Google AdSense.

🔗 Acesse o site aqui:  
👉 [https://jennial.github.io/blogGatos/](https://jennial.github.io/blogGatos/)

## 💡 O que você vai encontrar:
- Conteúdos atualizados sobre saúde, alimentação e comportamento dos gatos
- Posts renderizados dinamicamente via arquivos Markdown
- Espaços dedicados para anúncios (ads)
- Visual responsivo e amigável

Sinta-se à vontade para explorar, sugerir melhorias ou contribuir com o projeto!
